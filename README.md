## Run it


This writes the cover to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png` when set). Deterministic: the same bytes on every run, stdlib only, no network. The cover itself is rendered by `generate.py` (PIL, system DejaVu fonts) into `assets/entry.png`.
